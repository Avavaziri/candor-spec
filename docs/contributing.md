# Contributing

Candor is open. Anyone can propose a change.

- **Report a problem** with a requirement: open an [erratum issue](https://github.com/Avavaziri/candor-spec/issues/new?template=erratum.yml).
- **Propose a pattern**: open a [pattern proposal](https://github.com/Avavaziri/candor-spec/issues/new?template=pattern-proposal.yml). Do this before you write a pull request.
- **Fix the text**: use the "Suggest a change to this page" link at the bottom of any page.

Before you start, read:

1. the [contribution guide](https://github.com/Avavaziri/candor-spec/blob/main/CONTRIBUTING.md), for how to write and check a change;
2. the [governance document](https://github.com/Avavaziri/candor-spec/blob/main/GOVERNANCE.md), for how decisions are made;
3. the [pattern template](./spec/template), for the structure of every pattern;
4. the [Code of Conduct](https://github.com/Avavaziri/candor-spec/blob/main/CODE_OF_CONDUCT.md).
